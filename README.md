<h1>Some teams</h1>

<p>This project is about exercising php, html, css and github in the terminal and combining them to see how they work together. This work is also about some teams from Uefa and to display their team and stats</p>

The project was coded using `php`, `html` and `css` programming languages on `Visual Studio Code`. To create the page, html was used to create a base or an idea to build on and then built on a `index.php` file to add the data and 
avoid repetitive code. Each functions were made on a seperate branch on Github when working. They were created on terminal in Visual Studio Code and and later on pushed to Github. The main branch and a sub-main branch 
were merched on Github's site by using the pull request function.

The branches used on Github mainly and commands on terminal were:
```
Branches:
Main
Develop

Commands on Terminal used to update github:
git add .
git commit -m "Initial commit"
git push -u origin branchName
```

Data resources were gathered by a resource file issued by 
>my teacher.

A little about me: Hi, I am Henrik Hua, currently a student at Yrgo aspiring to become a webdeveloper and give life to website by code.

To download this and use it, you will need to download each and every file (especially the php and css files) and then open them in Visual Studio Code. Then go to `Terminal` tab on the upper navigation
and click `New terminal`. 

In the terminal change the it from windows powershell to Ubuntu and run following command: `php -S localhost:8000` and then type in `localhost:8000/index.php` in your local browser. 

Use at own risk.
